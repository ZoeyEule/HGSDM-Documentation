# Included Files and Third-Party Software

## Included

`WildMods_SSDM.uplugin`; Runtime and Editor module source; shader source included by `Config/FilterPlugin.ini`; showroom, Profiles, materials, material function, heightmaps and sample assets; icon; English documentation; README, changelog and credits.

Generated/local Binaries, Build, Intermediate, Saved, version-control metadata and private development notes are excluded.

## Modules

- `WildMods_SSDM` - Runtime.
- `WildMods_SSDMEditor` - Editor.

## Declaration

HGSDM includes no third-party software libraries and depends only on Unreal Engine modules shipped with UE5.8. Mesh Partition and Sensei are optional interoperability targets, not bundled, linked or required dependencies.

All shipped sample assets must be original WildMods work or material for which WildMods holds redistribution rights. Do not add third-party samples without recording the license and completing Epic's Third-Party Software declaration when required.
